chebuOS — Website 2.0

Открой index.html в браузере. Сайт полностью статический и работает без сервера.
Страницы:
  index.html — главная
  store.html — интерактивный каталог (не устанавливает программы)
  news.html — история выпусков
  community.html — локальное создание TXT-отзыва/баг-репорта

assets/style.css — стили; assets/site.js — анимации, навигация и часы.
assets/store.js — поиск и фильтрация каталога.
assets/community.js — скачивание отзыва.
downloads/chebuOS_1.6_NovaDesk.zip — сама оболочка для Windows.

Для публикации загрузи содержимое этой папки на статический хостинг.
Никакой серверной отправки сообщений и настоящего магазина загрузок пока нет.
